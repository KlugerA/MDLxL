# MDLxL 0.15.0

This release adds a visual Warcraft III particle and ribbon workflow while keeping the main editor compact.

- Open EMTR beside KEY and VIS, then choose an effect, edit it visually, or place it into the current model.
- Browse locally extracted classic Warcraft III effects, keep favorites and independent working drafts, and import ordinary or team pictures through the existing texture library.
- Pause, slow, scrub and inspect particles while editing. Shared sliders include exact numeric fields.
- Select, move and delete emitters through the Vertices and Bones views, attach or detach them from bones, and author visibility without changing RGB tracks.
- Create weapon ribbons by selecting the weapon's back polygons, choosing visible animations, and clicking Create. The fitted ribbon opens directly in the visual editor.
- Edit ribbon Basics, Appearance and Sweep controls while watching the native model animation.
- Save portable presets and retain custom picture dependencies, undo history and recovery drafts.
- Bones and Helpers are separated and color-coded in the object selector.
- Delete free vertices removes unreferenced vertices from selected geosets while preserving valid geometry streams and references.
- UV Wrapper scroll sensitivity starts at 1.0 each time the wrapper opens and stays local to that wrapper.

MDLxL 0.15.0 includes every change released in 0.14.1.
