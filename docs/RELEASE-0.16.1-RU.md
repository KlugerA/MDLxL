# MDLxL 0.16.1

Этот выпуск исправляет ленты оружия в EMTR и восстановление нормалей в NormalsXL.

- Новые ленты EMTR, подогнанные по выделенным полигонам, привязываются непосредственно к выбранной кости оружия, как у стандартного Blademaster. При сохранении идентификаторы узлов, родители и точки вращения остаются согласованными для других редакторов, включая Retera Model Studio. Новые материалы лент используют флаги Unshaded и TwoSided. Подогнанный край, текстура мягкого диска и отмеченные анимации атак сохраняются. Чтобы использовать исправленную привязку, создайте заново ленты, добавленные прежним ошибочным способом.
- NormalsXL больше не прерывает восстановление всей модели из-за треугольника нулевой площади. Такие грани остаются в модели, но не участвуют в определении ориентации. Для выделенных изогнутых поверхностей, нормали которых сведены к одной оси, локальные направления восстанавливаются по ориентированным прилегающим граням. Сохраняются существующие разделения вершин, заданные длины нормалей, остальные поверхности и выбор одной опорной вершины.
- Оба исправления сохраняют отмену, повтор и сохранение MDL/MDX. Установка обновления не изменяет исходные модели пользователя.

MDLxL 0.16.1 включает все изменения версии 0.16.0.
