# Showcase rendering target

Showcase records GIFs with a Z-axis turntable and Radius slider. At 0% radius, the model spins about its own origin without moving around a path. The path grows linearly to four times the previous apparent orbit radius at 100%. Its compact left menu contains RECORD, Length, backgrounds, the animation sequence, orbit preview/speed and graphics/light settings. 100% orbit speed is one revolution over the recording duration; 0% holds the angle and 200% makes two turns. Animation speed is independent. Local sequences play in order during recording; preview repeats the sequence. Global sequences always advance in wall time, including when local playback is paused, at 0%, or has reached its final pose.

The turntable rotates the displayed model around its own model origin. An inverse transform is applied to a render-only camera for the mesh, particles, billboards and events. The navigated camera, pan, zoom and projection remain unchanged. Portrait animation names do not change the camera or add a portrait frame.

Light has three choices: Ingame uses the existing classic directional preview light (0.55 ambient plus 0.45 diffuse); Portrait uses the existing classic vertex-lit portrait shader with a 0.3 ambient floor and direction [0.3, -0.3, 0.25]; None disables mesh lighting. These are presentation presets, not complete Warcraft terrain/day-night or model Light-node simulation. Original Unshaded material flags remain respected. Only the preview's renderer clone is used; model data is never rewritten.

Live recording follows elapsed wall time. Encoder backpressure skips intermediate captures instead of slowing the displayed sequence. Actual frame timestamps determine GIF delays and the final delay keeps the requested duration exact. Lossless frame compression runs on a dedicated worker thread. GIF palette/encoding passes run after capture with bounded FFmpeg filter threads. Progress updates are throttled to ten per second. Frame readback still uses the graphics/UI thread, so capture cost depends on resolution and hardware.

Quality changes preview sampling and GIF dimensions. Low uses 1x sampling, no AA, bilinear mip filtering, 1x anisotropy, a 720px GIF edge and 128 colors. Medium uses 1.5x sampling, AA, trilinear filtering, 4x anisotropy, a 1280px GIF edge and 256 colors. Highest uses 2x sampling, AA, trilinear filtering, up to 16x anisotropy, a 1920px GIF edge and 256 colors. GPU support can limit AA and anisotropy. Geometry, particles and source textures remain the same at all qualities.

Folder backgrounds load in Showcase. Image/Video accepts local images, animated GIFs and browser-decodable videos; videos are muted and loop inside the From/To interval. WAV is audio-only and cannot supply a background picture. GIFs and videos animate during live recording.

The WebGL2 war3-model renderer supports standard geometry and animation, global sequences, layered alpha, texture animation, ParticleEmitter2, and partial RibbonEmitter behavior. It does not provide full Warcraft III Light-node, render-priority, legacy ParticleEmitter or Popcorn rendering. Showcase is not a complete Warcraft III engine replacement.
