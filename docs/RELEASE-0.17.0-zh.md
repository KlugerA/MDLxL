# MDLxL 0.17.0 - 绘画、印章与选区

绘画系统围绕魔兽争霸 III SD 模型重新设计：从现有纹理或干净底色开始，选择部位，然后绘画，或借用魔兽及个人图片中的素材。

- 连续盖章，无需逐次确认。裁出图块、调整大小，用逗号/句号旋转、M 镜像，再点击或按住拖动放置。
- 按住 R 可从边缘外开始大画笔或大印章。绘画仍限制在可见表面、选中的几何区域和未受保护的像素内。
- 更清晰的自由套索与多边形选区：编号顶点、实时闭合边，以及可见的选中和保护区域。
- 五种画笔、相关色调板、可控混合、小画笔十字光标，以及完整图像 / 纹理 / 高光的直接切换按钮。
- Shift 添加部位，Ctrl 减去。复制粘贴图块、隔离部位、显示轮廓或预览部位颜色，并在绘画界面直接调整 UV。
- 当共用 UV 使其他部位跟着改变时，可为所选部位分配独立纹理像素。
- 五个原生游戏入门素材、个人纹理库，以及来源和目标纹理视图中的滚轮缩放和平移。
- 绘画界面支持英语、俄语、西班牙语、中文和魔多语模式。附带英语、俄语各两页的快速指南，位于 ZIP 内 resources/app/docs，也可从发布页单独下载。
- Grabthrough 在顶点编辑器中默认开启，在骨骼编辑器中默认关闭，各自独立切换。

保存绘画项目以保留图层。将绘画应用到模型后，请在编辑器中正常保存模型。导出可创建魔兽资源包。

原生魔兽素材使用你配置的游戏数据。第一次放置可能需要短暂准备投影，重复放置会复用投影。原始纹理和源文件会保留。

包含 0.16.1 的 EMTR 飘带和 NormalsXL 修复。

构建现已包含独立的 EMTR 素材库运行时，保留已安装版本中的修复，无需开发依赖即可使用。
