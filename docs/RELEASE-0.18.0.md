# MDLxL 0.18.0

- Simplified material, texture, node, and geoset managers with existing Animations visibility editing.
- Appearance presets now style folders and nodes individually. Background, folder, node, and font-size controls are available in collapsible sections, initially open.
- Paint Crop offers Rectangle, Square, Ellipse, and Circle. Selections remain adjustable with corner handles and inside dragging.
- All 31 curated Paint textures ship as organized defaults; personal texture files are preserved.
- UV Replace Texture replaces the full ordinary image-layer chain, including animated/modular layers, with one clean layer. Team color/glow, unrelated geosets, and old texture resources remain intact.

Extract the whole Windows ZIP and run MDLxL.exe.

Validation: compatibility and focused UV/material, Paint, resource-manager, and appearance tests; rebuilt production renderer; portable package validation and Electron checks. Existing unrelated historical source-suite failures are outside this release's acceptance checks.
