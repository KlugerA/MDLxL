# MDLxL 0.18.3

- Showcase no longer contains the anonymous GIF upload service, its link and BBCode controls, its desktop IPC, or its upload-specific encoding profile. Hive and original-quality local GIF export remain available.
- Bitz can collect a new part from the selected vertices across geosets, with RGB presets, live color preview, baked color animations, and preset import.
- Weighted models that use Classic materials now render through the correct preview path in Animations and Bones.
- Switching geoset color modes now commits the active RGB field first, preventing the final typed color edit from being lost.

The renderer bundle, focused source regressions, and Windows portable package are rebuilt for this release. Extract the whole Windows ZIP and run MDLxL.exe. Keep its folders together.
