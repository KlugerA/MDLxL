# MDLxL 0.17.0 - Рисование, штампы и выделение

Рисование переделано для SD-моделей Warcraft III: оставьте исходную текстуру или начните с чистой основы, выделите часть и рисуйте либо переносите фрагменты из Warcraft и своих изображений.

- Ставьте штампы один за другим без подтверждений. Вырежьте фрагмент, задайте размер, поверните клавишами запятая/точка, отразите M и поставьте щелчком или перетаскиванием.
- Держите R, чтобы начать большой штамп или мазок за краем. Краска по-прежнему ограничена видимой поверхностью, выделенной геометрией и защищёнными пикселями.
- Понятнее лассо и многоугольное выделение: номера углов, будущая замыкающая линия, видимые выделенные и защищённые области.
- Пять кистей, палитры близких цветов, регулируемое смешивание, заметный прицел маленькой кисти и прямой выбор: всё изображение / текстура / блики.
- Shift добавляет части, Ctrl вычитает. Копируйте и вставляйте рисунок, изолируйте части, включайте контуры или цвета частей, правьте UV прямо в Paint.
- Дайте выбранной части свои пиксели, если общая развёртка заставляет другую часть меняться вместе с ней.
- Пять примеров из игры, личная библиотека текстур, масштаб колесом и сдвиг в обоих окнах текстур.
- Рисование переведено на английский, русский, испанский, китайский и язык Мордора. Памятки на английском и русском занимают по две страницы; они лежат в resources/app/docs внутри ZIP и доступны отдельно в релизе.
- Grabthrough теперь **включён по умолчанию в Вершинах** и **выключен в Костях**. Переключатели независимы.

Сохраняйте проект рисования для продолжения работы со слоями. «Применить покраску к модели» вернёт результат в редактор; затем сохраните модель обычным способом. «Экспорт» создаёт пакет для Warcraft.

Источники Warcraft загружаются из подключённых данных игры. Первая постановка штампа может сделать паузу при подготовке проекции; повторные используют готовую проекцию. Исходные текстуры и файлы сохраняются.

Включены исправления лент EMTR и NormalsXL из 0.16.1.

Исправление библиотеки EMTR из установленной версии включено в сборку: переносимой программе больше не нужны зависимости среды разработки для этой библиотеки.
