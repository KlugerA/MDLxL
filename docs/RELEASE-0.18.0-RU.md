# MDLxL 0.18.0

- Упрощены менеджеры материалов, текстур, узлов и геосетов; используются существующие инструменты видимости Animations.
- Пресеты оформления имеют отдельные цвета папок и узлов. Доступны настройки цветов и размера шрифта в сворачиваемых разделах.
- В Paint доступны Rectangle, Square, Ellipse и Circle; область обрезки можно перемещать и изменять за углы.
- 31 текстура Paint поставляется в организованной библиотеке по умолчанию. Личные файлы сохраняются.
- Replace Texture в UV заменяет всю цепочку обычных слоёв изображения одним чистым слоем. Team color/glow, другие геосеты и старые ресурсы текстур сохраняются.

Распакуйте весь ZIP и запустите MDLxL.exe.
