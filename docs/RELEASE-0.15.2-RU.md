# MDLxL 0.15.2

Это обновление ускоряет поиск в библиотеке текстур и добавляет отдельную настройку выделения сквозь модель.

- Совпадения по имени и пути текстуры теперь появляются сразу из загруженного каталога, пока поиск Vibe продолжает индексирование в фоновом режиме.
- Когда полный результат Vibe готов, он по-прежнему заменяет быстрые буквальные совпадения.
- Если очистить запрос или отключить поиск Vibe, запоздалый фоновый результат больше не появится снова.
- В режимах Vertices и Bones добавлен флажок Grabthrough.
- По умолчанию Grabthrough выключен, поэтому в Textured View выделяются только видимые с поверхности вершины. Включите его, чтобы снова выделять вершины сквозь модель.
- Режим Movement не изменён и не показывает настройку Grabthrough.

MDLxL 0.15.2 включает все изменения версии 0.15.1.
