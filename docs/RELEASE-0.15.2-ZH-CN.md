# MDLxL 0.15.2

此补丁让纹理库搜索保持响应，并加入明确的穿透模型选择选项。

- Vibe 搜索在后台完成索引时，已加载目录中的纹理名称和路径匹配会立即显示。
- 完整的 Vibe 结果准备好后，仍会替换即时显示的字面匹配结果。
- 清空搜索或关闭 Vibe 搜索后，延迟返回的后台结果不会再次出现。
- Vertices 和 Bones 现在包含 Grabthrough 复选框。
- Grabthrough 默认关闭，因此 Textured View 只选择表面可见的顶点。打开它即可恢复穿透模型选择。
- Movement 保持不变，也不会显示 Grabthrough 控件。

MDLxL 0.15.2 包含 0.15.1 中发布的全部改动。
