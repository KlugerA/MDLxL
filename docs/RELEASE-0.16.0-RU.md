# MDLxL 0.16.0

Этот выпуск добавляет вкладки моделей и объединяет последние исправления редактирования, вставки, выделения и UV.

- Каждая открытая модель имеет собственную вкладку. Выделение и состояние вида сохраняются отдельно для каждой вкладки; окно просмотра создаётся только для активной модели.
- Копируйте геометрию или узлы сочетанием Ctrl+C, переключайтесь между вкладками и вставляйте через Ctrl+P или Ctrl+V. Геометрия получает настройки RGB из выбранного RGB Preview.
- Обычная вставленная геометрия привязывается к проверенной DummyBone. Корневые узлы скопированной иерархии используют ту же систему. При добавлении узлов сохраняются идентичность существующих узлов, точки вращения, дорожки анимации, родители и привязки геометрии. BitsAndParts и Forge используют исправленную общую обработку DummyBone.
- Последующие открытия файлов моделей направляются в уже открытое окно MDLxL и создают вкладки. Открывайте дополнительные файлы по очереди: одновременное открытие нескольких файлов при самом первом запуске ещё не полностью проверено.
- Небольшие правки моделей с большим количеством ключей анимации больше не вызывают повторное создание полного JSON-снимка для проверки изменений и передачу двух полных графов анимации через механизм восстановления. Анимация сохраняется; отмена и повтор, проверка сохранения и старые записи восстановления по-прежнему поддерживаются.
- При включённом Grabthrough скрытые маркеры вершин отображаются сквозь модель в Textured View в режимах Vertices и Bones. По умолчанию настройка выключена; Surface/Wireframe и глобальная настройка X-Ray не изменены.
- Project from Current View сохраняет центр выбранного UV-острова на его прежнем месте. Поворот камеры и масштаб управляют ориентацией и размером проекции; панорамирование больше не перемещает UV-остров. Невыделенные UV-координаты не меняются.

MDLxL 0.16.0 включает все изменения версии 0.15.2.
