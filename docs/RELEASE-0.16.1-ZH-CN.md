# MDLxL 0.16.1

此版本修复 EMTR 武器飘带和 NormalsXL 法线修复。

- 新建并按所选多边形拟合的 EMTR 飘带会直接绑定到所选武器骨骼，与原版 Blademaster 的方式一致。保存时，节点 ID、父节点和枢轴保持对应，供 Retera Model Studio 等外部编辑器正确读取。新飘带材质使用 Unshaded 和 TwoSided 标志。拟合边缘、柔边圆盘纹理和勾选的攻击动画保持不变。请重新创建由旧版错误流程添加的飘带，以使用修正后的绑定方式。
- NormalsXL 不再因零面积三角形而中止整个模型的修复。这些面仍保留在模型中，但不参与方向约束。对于法线塌缩到同一轴的所选曲面，可以根据相邻且方向一致的面恢复局部法线方向。已有顶点拆分、原有法线长度、其他表面和单个参考顶点的操作流程均保留。
- 两项修复均保留撤销、重做及 MDL/MDX 保存支持。安装更新不会修改用户的原始模型。

MDLxL 0.16.1 包含 0.16.0 中发布的全部改动。
