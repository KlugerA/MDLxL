# MDLxL 0.18.4

- Local Showcase GIF saves now use the former upload limits: an 864-pixel maximum edge and a 20 MiB cap while preserving frames, duration, looping, FPS, and palette choices.
- Optimizer validates canonical exported node IDs correctly and can optionally resample verified cubic spline spans without changing motion beyond its configured tolerance.

The renderer bundle and Windows portable package are rebuilt for this release. Extract the whole Windows ZIP and run MDLxL.exe. Keep its folders together.
