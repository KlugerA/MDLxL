# MDLxL 0.15.1

This patch translates the features added in 0.15 into every language available in MDLxL.

- Particle Editor controls, EMTR entry points, library actions, placement, playback, visual handles, pictures, ribbons and test views now have Russian, Spanish and Chinese text.
- Particle statuses, validation messages, starter effects, teaching examples and reviewed library appearance names are translated too.
- Bones/Helpers organization, emitter visibility controls and Delete free vertices messages are included.
- The Language of Mordor continues to use its intentional Black Speech cipher, now covering the new catalog.
- File paths, model names, user effect names, native data and technical identifiers remain unchanged.

MDLxL 0.15.1 includes every change released in 0.15.0.
