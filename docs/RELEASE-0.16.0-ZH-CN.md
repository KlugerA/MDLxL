# MDLxL 0.16.0

此版本加入模型标签页，并整合最新的编辑、粘贴、选择和 UV 修复。

- 每个打开的模型都有独立标签页，分别保留编辑器选择与视图状态。仅挂载当前模型的视口。
- 使用 Ctrl+C 复制几何体或节点，切换模型标签页后使用 Ctrl+P 或 Ctrl+V 粘贴。几何体会继承所选 RGB Preview 的 RGB 设置。
- 普通粘贴的几何体绑定到经过验证的 DummyBone，复制节点的根节点也使用同一套绑定系统。添加节点时保留已有节点身份、枢轴、动画轨道、父子关系和几何体绑定。BitsAndParts 和 Forge 共用修正后的 DummyBone 处理。
- 后续打开的模型文件会作为标签页进入现有 MDLxL 窗口。请逐个打开额外文件：首次启动时同时打开多个文件仍存在未完成的验证项。
- 对包含大量动画关键帧的模型进行小幅编辑时，不再反复生成整份模型的 JSON 来检查更改，也不再通过恢复桥传递两份完整动画数据图。动画数据保持不变；撤销、重做、保存验证及旧版恢复记录仍受支持。
- 开启 Grabthrough 后，Vertices 和 Bones 的 Textured View 会透过模型显示被遮挡的顶点标记。默认仍为关闭；Surface/Wireframe 行为及全局 X-Ray 设置保持不变。
- Project from Current View 保持所选 UV 岛的中心位置。相机旋转与缩放控制投影方向和尺寸，平移相机不再移动 UV 岛。未选中的 UV 坐标保持不变。

MDLxL 0.16.0 包含 0.15.2 中发布的全部改动。
